# Gutenberg engine

Editorial engine and complete desktop editor maintained in this repository. Initial source: DesignCraft0.2.1 revision 80b3e3cb74618b02f40b80ac7c2fa35e5da4e1af. Copyright/license notices remain in LICENSE-MIT, LICENSE-APACHE, NOTICE and ASSETS.md. The historical attribution inventory includes material not shipped here: only fonts/hyphenation and licensed source/test assets are included; product artwork is the existing Hoard icon. The protected brand mark was removed from the code.

Build with python scripts/build_engine.py. New documents use .gutenberg with application/vnd.gutenberg+zip and own metadata. Historical .designcraft ZIP/JSON documents and built-in CMYK profile names remain imports. Original files remain intact; normal publication editing uses an owned copy.
